ServerVault

荒らされても、元どおり。

ServerVault は、Discord サーバーの構成を保存・復元できるバックアップボットです。カテゴリ・チャンネル・ロールに加えて、サーバーの名前・アイコン・説明も保存します。

サーバーに招待する 機能を見る
  • スラッシュコマンド対応
  • 自動セーブつき
  • 荒らし検知つき

できること

サーバーの「いま」を金庫に預けて、必要な時に取り出せます。

💾

セーブ

今のサーバーの構成をそのまま保存します。金庫に預けるように、いざという時の備えになります。

📂

通常ロード

セーブした構成を復元します。今あるものは消さず、足りないものを作るだけなので安全です。

🚨

完全ロード

セーブに無いもの（スパム等）を消してから作り直し、全部をセーブ通りに戻します。

🗑️

セーブの削除

いらなくなったセーブは、確認画面つきで安全に消せます（管理者のみ）。

🔄

自動セーブ

24時間ごとに自動でセーブ。自動分は最新7件を保持し、手動セーブは消えません。

⚙️

サーバー設定の保存と復元

サーバーの名前・アイコン・説明も一緒に保存・復元します。

🛡️

荒らし検知 /guard

破壊的な操作を検知し、監査ログの実行者を管理者だけに警告します。バンは自動では行わず、管理者が2段階で確認した時だけです。

コマンド一覧

スラッシュコマンドと、! ではじまるコマンドの両方に対応しています。

機能スラッシュ!
セーブ /backup save !backup save
一覧 /backup list !backup list
ロード /backup load（モードで通常／完全を選べます） !backup load
削除 /backup delete !backup delete
自動セーブ /backup auto（オン／オフ／状態） !backup auto
使い方 /backup help !backup help
検知の確認 /guard log !guard log
通知先設定 /guard notify !guard notify

スラッシュは、チャット欄で / を打つと候補と説明が出るので、初めてでも迷いません。

導入の流れ

4つのステップで、すぐに使い始められます。

1

招待する

［サーバーに招待する］ボタンから、自分のサーバーに ServerVault を追加します。

2

ロールを上げる

サーバー設定 → ロール で ServerVault のロールを上の方へ。ロールが高い相手もバンできるようにするためです。

3

通知先を設定

/guard notify で、管理者だけが見られるチャンネルを荒らし警告の通知先にします。

4

最初のセーブ

/backup save で今の状態を保存すれば、準備完了です。

※参加したサーバーでは、最初に挨拶と使い方、設定案内が自動で表示されます。

⚠️ 知っておいてほしいこと

  • 復元できるのはサーバーの「構成」だけです。メッセージ履歴（投稿の内容そのもの）は復元できません。
  • 戻せるのは、セーブした時点の状態までです。セーブより後に作ったものは戻りません。
  • 完全ロードは、セーブに無いチャンネルやロールを削除します。削除したものは元に戻せません。
  • 自動セーブは、ボットが起動している間だけ動きます。
  • セーブ／ロードなどの操作は、サーバーの管理者だけが使えます。

よくある質問

Q荒らされたら、全部元に戻りますか？

セーブした時点の構成（チャンネル・カテゴリ・ロール・サーバー設定）に戻せます。ただしメッセージ履歴は復元できません。

Q勝手にバンされることはありますか？

ありません。検知しても警告までで、バンは管理者がボタンで2段階確認した時だけです。実行者は監査ログの記録がある時だけ表示し、記録が無い時は「特定できませんでした」と表示します（推測で名前を出すことはありません）。

Qどんな権限が必要ですか？

招待時に、チャンネルやロールの管理・監査ログの表示・バンなど10項目の権限を許可してください。どれもバックアップと検知のために使うものです。

Qスマホでも使えますか？

使えます。Discord アプリからスラッシュコマンドで操作できます。

Q無料ですか？

このページから招待して、自分のサーバーで使えます。
